## ⚖️ Overview

A **polished digital business card** for Adv. Yitzhak (Itzik) Cohen — a criminal defense attorney. Built mobile-first with full Hebrew RTL support, dark/light mode, animated UI and direct contact links.

> Live at: [Vercel deployment](https://yitzhak-cohen-lawyer.vercel.app)

## ✨ Features

- 🇮🇱 **Full Hebrew RTL** — Right-to-left layout with Heebo font
- 🌙 **Dark / Light Mode** — Toggle with smooth transition
- 📱 **Mobile-First** — Max-width 430px card, perfectly centered on desktop
- ☎️ **Quick Contact** — One-tap buttons for WhatsApp, phone, email, Waze
- ⭐ **Social Links** — Facebook, Instagram, sharing, and more
- 🎯 **Animated cursor** — Custom dot + ring cursor on desktop
- 📜 **Scroll progress bar** — Top progress indicator
- 💼 **About section** — Attorney bio with credentials
- ♿ **Accessible** — Semantic HTML, contrast-safe colors

<br/>

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 (RTL, `lang="he"`) |
| Styling | CSS3 — custom properties, animations, dark mode via `[data-theme=dark]` |
| Logic | Vanilla JavaScript (ES6+) |
| Font | Google Fonts — Heebo |
| Icons | Emoji + SVG inline |
| Hosting | Vercel |

## 🚀 Run Locally

No build step needed — open directly in browser:

```bash
git clone https://github.com/matan4749/Yitzhak_Cohen_Lawyer.git
cd Yitzhak_Cohen_Lawyer/cohen-card
open index.html   # macOS
# or: npx serve .
```
